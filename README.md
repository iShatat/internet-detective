# Internet Detective

A small game for Grade 5: read a message or a website and decide if it is FAKE or REAL.
Every message, sender and website in the game is made up, except a few well-known real websites.

Play it: https://ishatat.github.io/internet-detective/

The game is one HTML file with nothing to install. The player's name is used for that game only;
it is never saved or sent.
